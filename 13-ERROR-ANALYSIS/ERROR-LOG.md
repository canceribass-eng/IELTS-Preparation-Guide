## LISTENING - Hata Analizi

### Hata Kategorileri

#### 1. Yazım Hataları
```
Hatalı Cevap: "_________________"
Doğru Cevap: "_________________"
Neden Yaptığınız: ☐ Telaffuz Yanlış Anladı
                 ☐ Dikkat Dağıldı
                 ☐ Harf Karıştırdı
                 ☐ Dinamik Yazım Yok

Nasıl Düzeltilir:
→ Yazım kurallarını tekrar et
→ Kelimeyi 3 kez yazarak pratik yap
→ Dikkat seviyesini artır
```

#### 2. Dinleme Hatası
```
Hatalı Cevap: "_________________"
Doğru Cevap: "_________________"
Neden Yaptığınız: ☐ Kelimeyi Duymadı
                 ☐ Yanlış Anladı
                 ☐ Dikkat Kaydı
                 ☐ Aksan Yabancı

Nasıl Düzeltilir:
→ Kaydı yavaş hızda dinle
→ Aksan pratikleri yap
→ İlgili kelime setini çalış
```

#### 3. Not Alma Hatası
```
Hatalı Cevap: "_________________"
Doğru Cevap: "_________________"
Neden Yaptığınız: ☐ Hızlı Not Alamadı
                 ☐ Kısaltma Yanlış
                 ☐ Geç Başladı
                 ☐ Format Yanlış

Nasıl Düzeltilir:
→ Not alma hızını artır
→ Kendi kısaltmalarını geliştir
→ Sorular önceden oku
```

## READING - Hata Analizi

### Soru Türüne Göre Hatalar

#### Multiple Choice
```
Soru: "[Soru metni]"
Seçilen Cevap: ☐ A ☐ B ☐ C ☐ D
Doğru Cevap: ☐ A ☐ B ☐ C ☐ D

Hata Nedeni:
☐ Metin Yanlış Anladı
☐ Kelime Anlamını Bilemedi
☐ Tuzağa Düştü (yakın cevap)
☐ Tüm Pasaj Okumadı
☐ Zaman Sıkıntısı

Düzeltme Planı:
→ Pasajı yeniden oku
→ Neden diğer seçenekler yanlış?
→ Tuzaklar neler?
```

#### True/False/Not Given
```
Soru: "[Soru metni]"
Seçilen: ☐ True ☐ False ☐ NG
Doğru: ☐ True ☐ False ☐ NG

Hata Analizi:
☐ False ile NG karıştırdı
☐ Kelime anlamı yanlış
☐ Tam okumadı
☐ Çıkarım yaptı

Not: "Not Given" = Pasajda bilgi yok
     "False" = Bilgi var ama ters
```

#### Matching Headings
```
Pasaj: "_________________"
Seçilen Başlık: "_________________"
Doğru Başlık: "_________________"

Hata Nedeni:
☐ Ana fikri bulamadı
☐ Detay ile karıştırdı
☐ Tüm cümleleri okudu (zaman kaybı)
☐ Başlık anlamını bilemedi

Strateji:
→ İlk ve son cümleleri oku
→ Tekrarlanan kelimeyi bul
→ Başlık en geniş fikre uymal
```

## WRITING - Hata Analizi

### Task 1: Grafik Analizi

```
Grafik Türü: ☐ Bar ☐ Line ☐ Pie ☐ Table
Trend Yakaladınız mı: ☐ Evet ☐ Kısmen ☐ Hayır
Band Tahmini: ___________

Hatalar:

1. CONTENT (İçerik)
   ☐ Tüm veri yok
   ☐ Detay fazla/az
   ☐ Yanlış sonuç
   ☐ Comparisons eksik
   
   Düzeltme: Grafiğe 5 dakika daha bak

2. TASK ACHIEVEMENT (Görev Tamamlama)
   ☐ 150 kelimesinden az
   ☐ 4 paragraf yapısı yok
   ☐ Özet yok
   ☐ İçerik genel değil
   
   Düzeltme: Şablon kullan

3. COHERENCE & COHESION (Uyum)
   ☐ Bağlantı kelimesi yok
   ☐ Paragraflar dağınık
   ☐ Flow yok
   ☐ Tekrar fazla
   
   Düzeltme: Transition words listesi yap

4. VOCABULARY (Kelime)
   ☐ Basit kelimeler
   ☐ "went up/down" tekrarı
   ☐ "increased/decreased" tekrarı
   ☐ Yanlış kelime seçimi
   
   Düzeltme: Sinonimler öğren
   - increased → rose, climbed, surged
   - decreased → declined, dropped, fell

5. GRAMMAR (Dilbilgisi)
   ☐ Tense karışık
   ☐ Subject-verb uymayan
   ☐ Yazım hatası
   ☐ Preposition yanlış
   
   Düzeltme: Dilbilgisi kuralları tekrar et
```

### Task 2: Essay

```
Soru Türü: ☐ Agree/Disagree ☐ Discuss Both ☐ Problem-Solution ☐ Two Questions
Band Tahmini: ___________

1. TASK RESPONSE (Soruyu Cevapla)
   ☐ Pozisyon net
   ☐ Tüm parçalara cevap
   ☐ Ana argümanlar 2-3 var
   ☐ Her argüman desteklendi
   ☐ Sonu sonucu yeniliyor
   
   Hata: ___________________________
   Düzeltme: Paragraf yapısı: Giriş → Arg1 → Arg2 → Sonuç

2. COHERENCE & COHESION
   ☐ Paragraf başı cümleleri yok
   ☐ Bağlantı kelimesi az
   ☐ Akış kötü
   ☐ Tekrar fazla
   
   Hata: ___________________________
   Düzeltme: Her paragrafta 3-4 transition word

3. LEXICAL RESOURCE
   ☐ Tekrarlayan kelimeler
   ☐ Basit cümleler
   ☐ Yanlış kelime
   ☐ İfade yanlış
   
   Hata: ___________________________
   Düzeltme: Thesaurus kullan, sinonimler ara

4. GRAMMATICAL RANGE & ACCURACY
   ☐ Basit tense
   ☐ Hata sayısı fazla
   ☐ Kompleks cümle az
   ☐ Kural hataları
   
   Hata: ___________________________
   Düzeltme: Her hata türünü not et, pratik yap
```

## SPEAKING - Hata Analizi

```
Part Numarası: ☐ 1 ☐ 2 ☐ 3
Tarih: ___________
Band Tahmini: ___________

### FLUENCY & COHERENCE
☐ Duraklamalar fazla ("um", "er")
☐ Cümleler tamamlanmamış
☐ Konudan sapma
☐ Bağlantı az
☐ Hız uygun değil

Düzeltme:
→ Kendini kaydet
→ Tekrar dinle
→ Doğal expresyon pratik yap

### LEXICAL RESOURCE
☐ Tekrarlayan kelimeler
☐ "thing", "stuff" fazla
☐ Basit kelimeler
☐ Kolokasyon yok
☐ Parafraz yapamıyor

Düzeltme:
→ Kelime listesi oluştur
→ Cümle dönüştürme pratik yap
→ Sinonimleri öğren

### GRAMMATICAL RANGE & ACCURACY
☐ Basit cümleler
☐ Kompleks yapı az
☐ Hata sıklığı
☐ Tense tutarsız
☐ Word order hatalı

Düzeltme:
→ Kompleks cümleler yazı olarak prat yap
→ Gitmek için dilbilgisi kuralları tekrar

### PRONUNCIATION
☐ Telaffuz yanlış
☐ Vurgu yanlış (stress)
☐ Intonation monoton
☐ Sessiz/sesli uyumsuz
☐ Hız tutarsız

Düzeltme:
→ Fonetik semboller öğren
→ Native speaker dinle
→ Aynasının önünde pratik yap
```
